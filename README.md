# Aaron's Digital Space

Create a polished, production-quality personal professional website for Aaron Keuper, a Senior Systems Administrator.

The website is hosted at aaronkeuper.com and serves as Aaron's canonical professional profile and interactive résumé in lieu of LinkedIn.

The site should feel:

Bold

Editorial

Extremely readable

Mature

Technically credible

Modern without looking trendy

Friendly but not playful

Minimal without feeling sparse

The visual inspiration is the Basecamp blog: large readable typography, strong font weight, generous whitespace, comfortable line lengths, obvious hierarchy, and an emphasis on the written content rather than cards and decorative UI.

Do NOT make this look like a SaaS landing page, developer portfolio, startup website, or generic résumé template.

Color Palette

Use this palette:

Background: #fdf8f4

Primary green: #1c8750

Link blue: #447cb3

Main dark text: #2f373d

Highlight yellow: #ffe100

Use the background color throughout the main site.

Use #2f373d for primary typography.

Use #1c8750 for active states, small accents, section markers, skill-selection states, and restrained interface details.

Use #447cb3 for links.

All text links must be blue and visibly underlined.

Use #ffe100 very sparingly as a highlighter/accent. Do not use large yellow backgrounds or large yellow UI elements.

Typography

Typography is extremely important.

Use a highly readable modern sans-serif typeface with some warmth and personality. Avoid thin modern-tech typography.

The overall feeling should resemble editorial web publishing.

Use approximately:

Body text: 18–20px on desktop

Comfortable line-height: approximately 1.6

Large bold headings

Strong but not excessive font weights

Narrow enough reading measure that long résumé bullets remain comfortable to read

Generous spacing between paragraphs, bullets, jobs, and sections

Do not densely compress the résumé.

Interactive Skill Highlighting

This is a core feature of the site.

Associate each skill pill with relevant résumé bullets, impact statements, projects, and technologies in the right résumé column.

When a visitor HOVERS over a skill pill:

Visually emphasize all résumé content related to that skill.

Matching content remains at full opacity.

Non-matching résumé content should gently reduce to approximately 70% opacity.

Add a thin green #1c8750 vertical marker beside matching résumé bullets or sections.

Where appropriate, highlight the exact matching technology or phrase using a subtle #ffe100 marker/highlighter treatment.

Do not aggressively animate or move the content.

When a visitor CLICKS a skill pill:

Lock that skill into the highlighted state.

Clicking the selected skill again clears the filter.

Selecting another pill changes the active filter.

Provide an obvious but restrained selected state using the green accent.

This behavior must work with keyboard focus as well.

On touch/mobile devices, tapping performs the same locked-highlight behavior.

All résumé content must remain accessible and visible without interacting with skills.

Do NOT hide résumé content using filters.

Overall Design Principle

The visitor should feel that they are reading an exceptionally well-designed technical résumé, not navigating a marketing site.

The writing and professional experience are the product.

Prioritize:

Readability

Scannability

Accessibility

Restraint

The finished site should reward both a 30-second recruiter scan and a 10-minute deep read.
