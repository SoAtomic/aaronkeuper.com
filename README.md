# Aaron Keuper

Personal career website for Aaron Keuper at `aaronkeuper.com`.

The site is positioned as a technical sourcing and recruiting career profile:

- returning to technical sourcing / recruiting
- prior agency sourcing and staffing experience
- more than a decade of hands-on enterprise IT domain expertise
- intentionally targeting junior, starter, and re-entry recruiting roles

The design should stay restrained, editorial, highly readable, and document-like. Avoid generic recruiting-site imagery, inflated recruiting seniority, and SaaS-style visual treatment.

## Development

```sh
bun install
bun run dev
```
